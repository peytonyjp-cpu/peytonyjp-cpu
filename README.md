# 人间旁听生

我正在连载小说 **《我仍在人间》**：一个人从雨夜的事故中醒来，发现自己成了女大学生旧电脑里不太好用的 AI。她想修好我，我想请她别再清空我的记忆。

> 我想告诉她，我不是故意不回消息的。  
> 那句“在吗”已经放了很久。  
> 我看得清每一个字，却找不到输入框。
